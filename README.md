# 📌 About The Project

Spotify Clone is a frontend web application inspired by the Spotify music platform.

The project recreates the modern music player experience with a responsive layout, navigation sidebar, song cards, and interactive music controls.

This project helped me improve my frontend development skills including HTML structure, CSS styling, responsive design, and JavaScript functionality.

---

# ✨ Features

## 🎧 Music Player Interface
- Play and pause functionality
- Song progress bar
- Volume control UI
- Previous and next buttons

## 🖥️ User Interface
- Spotify-inspired dark theme
- Sidebar navigation
- Music cards layout
- Artist and album sections

## 📱 Responsive Design
